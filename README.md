# Акустический модем с ИИ-шумоподавлением (Acoustic Modem)

Android-приложение для бесконтактной передачи файлов между устройствами с помощью звуковых волн. Проект объединяет низкоуровневую обработку сигналов на C++ и современные методы машинного обучения для очистки звука от фонового шума.

## 🚀 О проделанной работе (Ключевые фичи)

В рамках проекта реализован полный цикл передачи данных через акустический канал:

* **Модуляция и демодуляция на C++:** Ядро приложения (JNI) преобразует любые бинарные файлы в аудиосигнал (несущая частота 8000 Гц) и обратно.
* **ИИ-шумоподавление (PyTorch Lite):** Интегрирована локальная нейросеть (`denoiser_mobile.ptl`), которая очищает записанный с микрофона эфир от посторонних шумов до начала расшифровки, повышая точность приема.
* **Адаптивный UI (Jetpack Compose):** Интерфейс приложения автоматически подстраивается под ориентацию экрана устройства (портретная/альбомная) с сохранением состояния процессов (передача/прием).
* **Асинхронная обработка:** Вся работа с файлами, генерацией звука и нейросетью вынесена в фоновые потоки (Coroutines), что гарантирует плавность интерфейса.

## 🛠 Технологический стек

* **Языки:** Kotlin, C++
* **UI-фреймворк:** Jetpack Compose
* **Машинное обучение:** PyTorch Mobile (LiteModuleLoader)
* **Аудио/Натив:** JNI, Oboe (для работы со звуком на уровне C++)

## ⚙️ Установка и запуск

Для использования приложения вам не нужно собирать его из исходного кода, достаточно установить готовый установочный файл.

1. Скачайте актуальный **APK-файл**(1 релиз)
* приложения на ваш Android-смартфон.
2. Откройте скачанный файл через любой файловый менеджер.
3. Если система безопасности Android заблокирует установку, нажмите «Настройки» во всплывающем окне и **разрешите установку из этого источника**.
4. Нажмите «Установить» и дождитесь завершения.
5. Запустите приложение с главного экрана телефона.

## 📱 Инструкция по пользованию

Для тестирования передачи данных вам потребуется два Android-устройства с установленным приложением.

### Подготовка
При первом запуске приложение запросит разрешение на использование микрофона. Оно критически необходимо принимающему устройству для прослушивания эфира.

### Отправка файла
1. На передающем устройстве нажмите кнопку **Отправить**.
2. В открывшемся системном окне выберите файл, который хотите передать.
3. Дождитесь завершения модуляции (статус отображается внизу экрана).
4. Устройство начнет воспроизводить специальный звуковой сигнал (звук модема).

### Прием файла
1. Положите принимающее устройство рядом с передающим.
2. Одновременно с началом воспроизведения звука (или за долю секунды до) нажмите кнопку **Получить** на принимающем устройстве.
3. Дождитесь окончания звукового сигнала и нажмите **Стоп**.
4. Приложение автоматически:
   * Прогонит запись через нейросеть для удаления шумов комнаты.
   * Расшифрует аудиосигнал обратно в байты.
   * Сохранит итоговый файл в папку `Downloads` (Загрузки) под именем `received_file.bin`.

**Примечание для тестов:** Для достижения наилучших результатов проводите передачу в условиях минимального постороннего шума, не меняя дистанцию между смартфонами во время сеанса связи.
